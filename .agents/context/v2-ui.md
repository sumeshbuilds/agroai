# AgroAI v2 interface

Mode: Operate. Scope: dashboard, Land Security, Plant Security, activity, settings, and authentication. The user approved direct implementation of the supplied Brainly-inspired UI and the requirements in v2.md.

## Direction contract

THESIS: A farm companion makes field monitoring and crop care two obvious, actionable paths; reject the old map-dominated dashboard.

OWN-WORLD: Soft white cards on light neutral ground, lime selections, purple progress, rounded black type, original plant character, and tactile agricultural illustrations.

STORY: Choose the real field and crop, inspect monitoring status, then complete a useful care routine. Missing data stays missing.

FIRST VIEWPORT: Character-led greeting, field/crop controls, two prominent security cards, and a visible crop journey; mobile preserves the two-card rhythm and floating four-item navigation.

FORM: User-pinned reference direction overrides seed f3c9130a. Code-led, explicitly chosen by the user. Task completion opens one lime feedback sheet; alerts remain serious.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
