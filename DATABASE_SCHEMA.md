# AgroAI - Neon Postgres Database Schema

## 1. Initial Setup SQL (Optional PostGIS extension in Neon SQL Editor)
```sql
CREATE EXTENSION IF NOT EXISTS postgis;
```

## 2. Drizzle ORM Schema (`src/db/schema.ts`)
Use the following table structures for Neon Serverless Postgres:

```typescript
import { pgTable, serial, integer, text, doublePrecision, timestamp, jsonb, boolean } from 'drizzle-orm/pg-core';

// 1. Farmers / Users Table
export const farmers = pgTable('farmers', {
  id: serial('id').primaryKey(),
  name: text('name').notNull(),
  phone: text('phone').notNull().unique(),
  language: text('language').default('en').notNull(), // e.g., 'en', 'hi', 'or'
  pushSubscription: jsonb('push_subscription'), // Web Push JSON object
  createdAt: timestamp('created_at').defaultNow(),
});

// 2. Farmlands Table (Stores GeoJSON Polygon + Centroid)
export const farmlands = pgTable('farmlands', {
  id: serial('id').primaryKey(),
  farmerId: integer('farmer_id').references(() => farmers.id),
  name: text('name').notNull(), // e.g., "North Paddy Field"
  polygonGeoJson: jsonb('polygon_geojson').notNull(), // Array of [lat, lng] coordinates
  centroidLat: doublePrecision('centroid_lat').notNull(),
  centroidLng: doublePrecision('centroid_lng').notNull(),
  areaAcres: doublePrecision('area_acres'),
  createdAt: timestamp('created_at').defaultNow(),
});

// 3. Crops Table
export const crops = pgTable('crops', {
  id: serial('id').primaryKey(),
  farmlandId: integer('farmland_id').references(() => farmlands.id),
  cropName: text('crop_name').notNull(), // e.g., "Paddy (Rice)", "Maize", "Tomato"
  sowingDate: timestamp('sowing_date').notNull(),
  growthStage: text('growth_stage').default('Seedling'),
  isActive: boolean('is_active').default(true),
  createdAt: timestamp('created_at').defaultNow(),
});

// 4. Animal / Hazard Intrusion Logs
export const intrusionAlerts = pgTable('intrusion_alerts', {
  id: serial('id').primaryKey(),
  animalType: text('animal_type').notNull(), // e.g., "Wild Boar", "Elephant Herd", "Tiger", "Thermal Fire"
  lat: doublePrecision('lat').notNull(),
  lng: doublePrecision('lng').notNull(),
  source: text('source').default('FOREST_SATELLITE_GRID'), // e.g., 'NASA_FIRMS', 'COMMUNITY_SIGHTING', 'EDGE_CAM'
  severity: text('severity').default('HIGH'),
  createdAt: timestamp('created_at').defaultNow(),
});

// 5. Weekly AI Crop Reports
export const weeklyReports = pgTable('weekly_reports', {
  id: serial('id').primaryKey(),
  cropId: integer('crop_id').references(() => crops.id),
  weatherSummary: jsonb('weather_summary').notNull(),
  aiActionPlan: text('ai_action_plan').notNull(), // Markdown generated by Gemini
  createdAt: timestamp('created_at').defaultNow(),
});
```

## 3. Spatial Distance Logic (For Intrusion Detection)
When a new animal sighting `(animalLat, animalLng)` is posted to `/api/alerts/check`, execute the Haversine distance check against `farmlands.centroidLat` and `farmlands.centroidLng` to find all farms within a 3.0 km radius:

```sql
SELECT * FROM (
  SELECT id, farmer_id, name, centroid_lat, centroid_lng,
    (6371 * acos(
      LEAST(1.0, GREATEST(-1.0,
        cos(radians($1)) * cos(radians(centroid_lat)) *
        cos(radians(centroid_lng) - radians($2)) +
        sin(radians($1)) * sin(radians(centroid_lat))
      ))
    )) AS distance_km
  FROM farmlands
) AS distances
WHERE distance_km <= 3.0
ORDER BY distance_km ASC;
```
